# AI-assisted codebase practice

Practice repositories for Amazon-style **AI-assisted debugging OAs**: an unfamiliar codebase with seeded bugs,
tests as the spec, and a restricted AI assistant (see each folder's `CLAUDE.md`).

| Folder | Stack | Brief |
|--------|-------|-------|
| [`oa-01-shoplite`](oa-01-shoplite) | MERN (Express, Mongoose, React) | E-commerce store: catalog, cart, orders, analytics |
| [`oa-02-returns-cpp`](oa-02-returns-cpp) | C++17, CMake | Return-policy engine: JSON parser, rule engine, CLI |

Each folder has its own README with setup, tickets and a "done when" checklist.
Start the restricted assistant by running `claude` **inside** a practice folder.
